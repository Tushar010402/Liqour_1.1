TROUBLESHOOTING:
================================================================================

If deployment fails:
1. Check logs: docker-compose -f docker-compose.production.yml logs
2. Restart service: docker-compose -f docker-compose.production.yml restart <service>
3. Full rebuild: docker-compose -f docker-compose.production.yml down -v && ./deploy.sh

- Go version mismatch: FIXED (GOTOOLCHAIN=auto added to all Dockerfiles)
