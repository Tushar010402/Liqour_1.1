### 5. Bank Reconciliation

**What it is:** Match your records with bank statements.

#### How It Works

```
1. Import Bank Statement
   (CSV or manual entry)
         │
         ▼
2. Match Transactions
   (Auto-match common items)
         │
         ▼
3. Review Differences
   (Unmatched transactions)
         │
         ▼
4. Resolve Issues
   (Add missing entries)
         │
         ▼
5. Complete Reconciliation
```

#### Reconciliation Status

| Status | Meaning |
|--------|---------|
| **Matched** | Bank and system agree |
| **Pending** | Waiting for bank to clear |
| **Difference** | Amounts don't match |
| **Not Found** | In bank, not in system |

### 6. Daily Reconciliation

**What it is:** End-of-day cash and sales matching.

#### Daily Close Process

| Step | What to Do |
|------|------------|
| **Count Cash** | Physical count of drawer |
| **Enter Count** | Record in system |
| **Review Difference** | Compare with expected |
| **Explain Variance** | Note any difference |
| **Approve Close** | Manager sign-off |

#### What Gets Checked

| Check | Purpose |
|-------|---------|
| Cash in drawer | Against sales records |
| Card transactions | Against terminal totals |
| UPI payments | Against app records |
| Credit sales | Against customer accounts |

## Common Questions

### "How do I close the day?"

1. Go to Finance → Day Close
2. Count physical cash
3. Enter cash count
4. System shows expected vs. actual
5. Note any difference with reason
6. Submit for approval

### "What if cash doesn't match?"

- System allows small variance (configurable)
- Large differences need manager approval
- All variances logged for review
- Can add adjustment entry with reason

### "How do I pay a supplier?"

1. Go to Finance → Payables
2. Select supplier
3. Click "Make Payment"
4. Enter amount and method
5. Add reference number
6. Save payment

### "Where do I see what I owe and what's owed to me?"

- **Receivables**: Finance → Receivables (what customers owe)
- **Payables**: Finance → Payables (what you owe suppliers)
- Dashboard shows summary of both
