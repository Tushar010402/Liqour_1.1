# Multi-Shop Module (Tenant Management)

Manage multiple store locations from one place - perfect for businesses with more than one shop.

---

## What This Module Does

The Multi-Shop Module lets you run multiple locations as one business:

| Capability | What It Means For You |
|------------|----------------------|
| **Centralized Dashboard** | See all shops at a glance |
| **Individual Settings** | Each shop can have its own rules |
| **Stock Visibility** | Know what's available where |
| **Stock Transfers** | Move products between locations |
| **Consolidated Reports** | Combined view across all shops |

---

## Key Features

### 1. Shop Management

**What it is:** Set up and manage each store location.

#### Shop Profile Information

| Information | Purpose |
|-------------|---------|
| **Shop Name** | Identify the location |
| **Address** | Full address with landmark |
| **Contact** | Phone, email for the shop |
| **License Details** | Excise license, validity |
| **Operating Hours** | When the shop is open |
| **Manager** | Who's responsible |

#### Each Shop Can Have

| Setting | Example |
|---------|---------|
| Own receipt format | Different headers/footers |
| Own pricing | Location-based pricing |
| Own staff | Assigned employees |
| Own inventory | Separate stock counts |
| Own customers | Local customer database |

---

### 2. Centralized Dashboard

**What it is:** One screen to see everything across all shops.

#### What You Can See

| Metric | Details |
|--------|---------|
| **Real-time Sales** | Live sales figures per shop |
| **Transaction Count** | Number of bills per shop |
| **Stock Status** | Green/yellow/red indicator |
| **Online Status** | Is shop connected? |
| **Staff On Duty** | Who's working now |

---

### 3. Stock Visibility

**What it is:** Know what's available across all locations.

#### Stock Overview

| View | What It Shows |
|------|---------------|
| **By Product** | See quantity at each shop |
| **By Shop** | All products and quantities |
| **Low Stock** | Products running low at any location |
| **Combined** | Total inventory across all shops |

---

### 4. Stock Transfers

**What it is:** Move products between your shops.

#### Transfer Features

| Feature | Benefit |
|---------|---------|
| **Transfer Notes** | Document why transfer is needed |
| **Partial Receipt** | Accept items as they arrive |
| **Damage Reporting** | Note any damaged goods |
| **Transfer History** | Track all past movements |

---

### 5. Pricing Control

**What it is:** Set prices across shops - same or different.

#### Pricing Options

| Option | When to Use |
|--------|-------------|
| **Uniform Pricing** | Same prices everywhere |
| **Location-based** | Different prices per shop |
| **Hybrid** | Some products same, some different |

---

### 6. Staff Management

**What it is:** Assign and manage staff across locations.

#### Roles Across Shops

| Role | Shop Access |
|------|-------------|
| **Owner** | All shops |
| **Admin** | All shops |
| **Regional Manager** | Assigned group of shops |
| **Shop Manager** | Single shop |
| **Staff** | Assigned shop only |

---

### 7. Consolidated Reporting

**What it is:** Combined reports across all your shops.

#### Report Types

| Report | What It Shows |
|--------|---------------|
| **Group Sales** | Total sales across all shops |
| **Shop Comparison** | Which shop performs best |
| **Product Performance** | Best sellers per location |
| **Staff Performance** | Compare staff across shops |

---

## Success Metrics
