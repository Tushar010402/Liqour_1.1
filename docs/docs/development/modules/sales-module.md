# Sales Module (Point of Sale)

Your digital cash register - handle all sales transactions quickly and accurately.

---

## What This Module Does

The Sales Module is the heart of daily operations:

| Capability | What It Means For You |
|------------|----------------------|
| **Quick Billing** | Complete sales in seconds |
| **Multiple Payments** | Cash, card, UPI, credit - all accepted |
| **Returns & Refunds** | Process returns without hassle |
| **Discounts & Offers** | Apply promotions automatically |
| **Sales Tracking** | Complete record of every transaction |

## Key Features

### 1. Quick Billing

**What it is:** The fastest way to complete sales.

#### How It Works

```
1. Start New Sale
       │
       ▼
2. Add Products

   - Quick buttons
       │
       ▼

       │
       ▼

       ▼
```

### 2. Payment Processing

**What it is:** Accept any payment method your customers prefer.

#### Supported Payment Methods

| Method | How It Works |
|--------|--------------|
| **Cash** | Enter amount, system calculates change |
| **Card** | Swipe/tap, wait for approval |
| **UPI** | Show QR code or enter UPI ID |

| **Cheque** | Record cheque details |

#### Split Payments

Customers can pay using multiple methods:

| Example | How |
|---------|-----|
| "Rs.500 cash, rest on card" | Add cash payment, then add card payment |
| "Half credit, half cash" | System splits automatically |
| "Pay Rs.100 now, credit the rest" | Partial payment with balance tracked |

#### Cash Handling

| Feature | What It Does |
|---------|--------------|
| **Change Calculator** | Shows exact change to give |
| **Cash Shortcuts** | Quick buttons for Rs.100, Rs.500, etc. |
| **Cash Drawer** | Opens automatically after sale |
| **End-of-Day Count** | Reconcile cash with sales |

### 4. Returns & Refunds

**What it is:** Process returns quickly while protecting against fraud.

#### Return Process

```
1. Find Original Sale
   (By receipt number or date)
         │
         ▼
2. Select Items to Return
   (Full or partial return)
         │
         ▼
3. Select Return Reason
   - Customer changed mind
   - Product damaged
   - Wrong product given
         │
         ▼
4. Process Refund
   - Same payment method
   - Store credit
   - Cash refund
         │
         ▼
5. Stock Updated Automatically
```

#### Return Rules

| Rule | Setting |
|------|---------|
| **Return Window** | Within X days of purchase |
| **Receipt Required** | Yes/No setting |
| **Approval Required** | For returns above Rs.X |
| **Restocking Fee** | Optional percentage deduction |

#### Refund Options

| Option | When Used |
|--------|-----------|
| **Same Method** | Refund to card if paid by card |
| **Cash** | Immediate cash refund |
| **Store Credit** | Add to customer balance |
| **Exchange** | Swap for different product |

## Common Questions

### "What if the internet goes down?"

LiquorPro works offline:
- Continue making sales normally
- All data saved locally
- Automatically syncs when connected
- No sales lost ever

### "Can I cancel a sale after it's done?"

Yes, with proper controls:
- Find the sale in history
- Click "Void" button
- Enter reason for voiding
- Manager approval may be required
- Stock automatically restored

### "How do I handle a wrong price?"

Two options:
1. **Before completing**: Edit the item price
2. **After completing**: Process return and resell correctly

### "What if customer wants detailed GST invoice?"

- LiquorPro generates GST-compliant invoices
- Customer details captured automatically
- GSTIN can be added for B2B sales
- Invoice format meets legal requirements

### "Can I set up automatic discounts?"

Yes! Configure once, apply automatically:
- Time-based (happy hours)
- Quantity-based (bulk discounts)
- Customer-based (loyalty discounts)
- Product-based (promotional pricing)
