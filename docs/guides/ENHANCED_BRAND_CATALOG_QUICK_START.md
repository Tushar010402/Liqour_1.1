## 📱 How to Use

### Step 1: Open Brand Catalog

**From Products List Screen**:
1. Tap **"Onboard Brands"** button (blue outlined button near top)
   - OR tap **"Onboard from SaaS Catalog"** in overflow menu (3 dots)

**You'll see the new enhanced catalog!**

---

### Step 2: Select Your Shop

**Shop Selector** (at the top):
- First shop is **auto-selected** for you
- Change shop using dropdown if needed
- All products will be added to this shop

**Important**: Shop is selected FIRST to prevent errors!

---

### Step 3: Choose Stock Entry Mode

**Toggle Button** (top right):
- **"Stock Later"** = Just onboard products (set stock later)
- **"With Stock"** = Enter stock quantities now (recommended)

**Tap to toggle** between modes.

When "With Stock" is active:
- Stock input fields appear on each product card
- You can set quantities inline (no navigation)

---

### Step 4: Browse by Category

**Category Tabs** (below shop selector):
- **All** - Shows all brands
- **Whisky** 🥃 - Scotch, bourbon, etc.
- **Rum** 🍹 - White rum, dark rum, etc.
- **Vodka** 🍸 - Plain, flavored, etc.
- **Gin** 🍸 - London dry, etc.
- **Beer** 🍺 - Lager, ale, etc.
- **Wine** 🍷 - Red, white, etc.

**Tap a category tab** to filter brands.

**Subcategory Chips** (appear below tabs):
- When you select a category, subcategories appear
- **Example**: Whisky → Scotch, Bourbon, Irish, etc.
- Tap subcategory chip to filter further
- Tap "All Whisky" to see all in category

---

### Step 5: Search (Optional)

**Search Bar** (below shop selector):
- Type brand name or product name
- Results filter instantly
- Works across all categories

**Example**: Type "johnnie" to find Johnnie Walker

---

### Step 6: Select Products

**Product Cards** (main scrollable list):

Each card shows:
- ✅ Checkbox (tap to select)
- 📷 Product image (or liquor icon)
- 📝 Brand name + size (e.g., "Johnnie Walker Red Label 750ml")
- 💰 MRP (Maximum Retail Price)
- 🍺 ABV (Alcohol by Volume %)
- 🔢 Barcode & HSN code

**To Select**:
1. Tap anywhere on the card
2. Checkbox turns blue ✅
3. Border highlights in blue
4. Card slightly elevated

**To Deselect**: Tap card again

---

### Step 7: Enter Stock Quantities (If "With Stock" Mode)

When you select a product, **stock input appears** on the card:

**Text Input**:
- Tap the large center field
- Type quantity (numbers only)
- Example: "50" for 50 units

**Quick Buttons** (on the right):
- **+10** - Add 10 units
- **+50** - Add 50 units
- **-10** - Subtract 10 units
- **Clear** - Reset to 0

**Tips**:
- Use +50 for high-volume products
- Use +10 for fine-tuning
- Use Clear to reset mistakes

---

### Step 8: Review Selection

**Floating Action Button** (bottom center):
- Shows selected count: "Onboard (3)"
- Appears when 1+ products selected
- Large, easy to tap with thumb

**App Bar Badge** (top right):
- Shows "3 selected" in blue bubble
- Quick visual confirmation

---

### Step 9: Onboard Products

**Tap "Onboard (X)" button** at bottom:

1. Confirmation dialog appears
   - Shows product count
   - Shows stock info (if applicable)
2. Tap **"Confirm"** to proceed
3. Loading indicator appears
4. Products are created
5. Stock quantities saved (if entered)
6. Success message shows: "Successfully onboarded 3 products"
7. Auto-navigate back to product list

**Done!** Your products are now in inventory with stock.

## 💡 Pro Tips

### Tip 1: Use Quick Buttons for Speed
- **+50** for popular items (fast movers)
- **+10** for moderate stock
- Combine buttons: Tap +50, then +10, then +10 = 70 units

### Tip 2: Category Navigation is Fast
- Start with category (Whisky, Rum, etc.)
- Then refine with subcategory (Scotch, Bourbon)
- Faster than scrolling through 200 brands

### Tip 3: Search is Your Friend
- Know the brand? Type it!
- Example: "jack daniels" → instant results
- Faster than browsing categories

### Tip 4: Stock Later is OK
- If you're busy, use "Stock Later" mode
- Onboard products quickly
- Set stock when you receive inventory

### Tip 5: Shop Context Matters
- First shop auto-selected (usually correct)
- Double-check shop before onboarding
- Products go to ONE shop at a time

### Tip 6: Batch Similar Products
- Onboard all whiskies together
- Then all rums, etc.
- Organized by category = easier inventory

## 🐛 Troubleshooting

### Issue: Enhanced Catalog Doesn't Show

**Symptom**: Old catalog appears (expansion tiles)

**Solution**:
1. Kill Flutter app (press 'q' in terminal)
2. Restart: `flutter run -d "iPhone 16"`
3. Or hot restart: Press 'R' in terminal

---

### Issue: No Categories Showing

**Symptom**: Only "All" tab appears

**Possible Causes**:
- No brands in SaaS catalog
- Brands missing `category_name` field

**Solution**:
1. Check SaaS admin has created brands
2. Verify brands have categories assigned
3. Contact admin to add categories

**Workaround**: Use "All" tab + search

---

### Issue: Stock Not Saving

**Symptom**: Products onboarded but stock is 0

**Possible Causes**:
- Stock input not entered
- "Stock Later" mode active
- API error

**Solution**:
1. Verify "With Stock" toggle is ON (blue)
2. Check stock input fields are visible
3. Enter quantities before onboarding
4. Check success message mentions stock

**Debug**:
- Check inventory service logs: `docker logs liquorpro-inventory`
- Look for stock adjustment errors

---

### Issue: Products Not Appearing in List

**Symptom**: Onboarding succeeds but products missing

**Possible Causes**:
- Wrong shop selected
- Filter active on products list
- Cache not refreshed

**Solution**:
1. Go to Products List
2. Pull down to refresh (swipe down)
3. Check shop filter matches onboarded shop
4. Clear category/brand filters

---

### Issue: Slow Performance (100+ Brands)

**Symptom**: Scrolling laggy, search slow

**Possible Causes**:
- Too many brands loaded
- Simulator performance
- Memory leak

**Solution**:
1. Use category filters (reduces visible items)
2. Use search (narrows results)
3. Test on real device (better performance)
4. Restart app: `flutter run`

**Expected**: Smooth 60fps even with 1000 variants
