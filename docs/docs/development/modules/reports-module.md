Turn your data into actionable insights to grow your business.

The Reports Module helps you understand your business through data:

| Capability | What It Means For You |

### 6. Custom Reports

**What it is:** Build reports specific to your needs.

#### Custom Report Features

| Feature | What It Does |
|---------|--------------|
| **Select Fields** | Choose columns to include |
| **Add Filters** | Date range, product, customer |
| **Choose Format** | Table, chart, or both |
| **Save Template** | Reuse later |
| **Schedule** | Auto-generate and send |

#### Creating Custom Reports

```
1. Go to Reports → Custom
         │
         ▼
2. Select Data Source
   (Sales, Inventory, Customers)
         │
         ▼
3. Choose Fields
   (What columns to show)
         │
         ▼
4. Add Filters
   (Date range, categories)
         │
         ▼
5. Preview Report
         │
         ▼
6. Save Template
   (For future use)
```

## Common Questions

### "How do I see today's sales?"

Go to Reports → Sales → Daily Sales
Or check the Dashboard for quick summary

### "Can I get reports automatically?"

Yes! Schedule reports:
1. Open any report
2. Click "Schedule"
3. Set frequency
4. Enter email address
5. Save

### "How do I compare this month to last month?"

1. Select "Sales Trend" report
2. Set date range for comparison
3. System shows side-by-side data
4. Charts highlight differences

### "Can I create my own report?"

Yes! Custom reports let you:
- Pick any data fields
- Apply any filters
- Save for reuse
- Schedule delivery
