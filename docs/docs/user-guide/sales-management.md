# Sales Management Guide

## Overview

This guide covers all aspects of sales management in LiquorPro, from daily sales entry to returns processing.

---

## 1. Daily Sales Entry

### 1.1 Accessing Daily Sales

1. Open LiquorPro app
2. Navigate to **Home** > **+ New Daily Sales**
3. Verify date and shop are correct

### 1.2 Bulk Entry Process

The bulk entry grid allows rapid data entry:

1. **Search Product**: Type product name or scan barcode
2. **Enter Quantity**: Input quantity sold
3. **Verify Price**: Auto-filled from catalog
4. **Add Discount**: Optional discount with reason
5. **Repeat**: Continue for all products

### 1.3 Adding Expenses

Include daily shop expenses:
- Transport costs
- Packaging materials
- Other operational expenses

### 1.4 Saving & Submitting

- **Save Draft**: Saves work without submitting
- **Submit**: Sends for manager approval

---

## 2. Sales Returns

### 2.1 Processing Returns

1. Go to **Sales** > **Sales History**
2. Find the original sale
3. Tap **Process Return**
4. Select items to return
5. Enter return reason
6. Confirm return

### 2.2 Return Reasons

Common return reasons:
- Customer changed mind
- Defective product
- Wrong product given
- Quality issues

---

## 3. OCR Receipt Processing

### 3.1 Uploading Receipts

1. Navigate to **Upload Receipts**
2. Select images (up to 200)
3. Wait for AI processing
4. Review extracted data
5. Confirm and save

### 3.2 Best Practices

- Good lighting for photos
- Capture entire receipt
- Flatten creased receipts
- Avoid blurry images

---

## 4. Approval Status

Track your submissions:
- **Draft**: Not yet submitted
- **Pending**: Awaiting approval
- **Approved**: Manager approved
- **Rejected**: Needs correction

---

## 5. Reports

Access sales reports:
- Daily sales summary
- Product-wise breakdown
- Performance trends
- Export options (PDF, Excel)
