# Finance Management Guide

## Overview

This guide covers financial operations in LiquorPro, including cash management, expenses, and vendor ledger.

---

## 1. Cash Collection

### 1.1 The 15-Minute Rule

After daily sales approval:
- Assistant Manager has 15 minutes to collect cash
- Warning at 10-minute mark
- Escalation if deadline missed

### 1.2 Recording Collection

1. Receive approval notification
2. Go to **Finance** > **Collections**
3. Enter collected amount
4. Add notes if needed
5. Submit

---

## 2. Bank Deposits

### 2.1 Recording Deposits

1. Navigate to **Finance** > **Bank**
2. Select **+ New Deposit**
3. Enter amount and bank account
4. Add reference number
5. Save

---

## 3. Expense Management

### 3.1 Recording Expenses

1. Go to **Finance** > **Expenses**
2. Tap **+ New Expense**
3. Select category
4. Enter amount
5. Upload receipt
6. Submit for approval

### 3.2 Expense Categories

- Transport
- Packaging
- Utilities
- Maintenance
- Miscellaneous

---

## 4. Vendor Management

### 4.1 Vendor Ledger

View all vendor transactions:
1. Navigate to **Finance** > **Vendors**
2. Select vendor
3. View ledger statement

### 4.2 Recording Payments

1. Open vendor ledger
2. Tap **Record Payment**
3. Enter amount and method
4. Add reference
5. Save

---

## 5. Daily Reconciliation

### 5.1 End of Day

1. Go to **Finance** > **Reconciliation**
2. Review totals
3. Verify cash count
4. Explain any variance
5. Close day

---

## 6. Reports

Available finance reports:
- Cash flow summary
- Expense breakdown
- Collection status
- Vendor statements
- Daily reconciliation
