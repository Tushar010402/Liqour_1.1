# Inventory Management Guide

## Overview

This guide covers inventory management in LiquorPro, including stock tracking, purchases, and transfers.

---

## 1. Product Catalog

### 1.1 Viewing Products

1. Navigate to **Inventory** > **Products**
2. Use search or filters
3. View product details

### 1.2 Product Information

Each product shows:
- Name and SKU
- Category and brand
- Price (cost and selling)
- Current stock level
- Reorder level

---

## 2. Stock Management

### 2.1 Checking Stock Levels

1. Go to **Inventory** > **Stocks**
2. Filter by shop if needed
3. View current quantities

### 2.2 Stock Indicators

- **Green**: Above reorder level
- **Yellow**: Near reorder level
- **Red**: Below reorder level

### 2.3 Low Stock Alerts

Receive notifications when:
- Stock falls below reorder level
- Products approaching expiry

---

## 3. Purchase Orders

### 3.1 Creating Purchase Order

1. Navigate to **Inventory** > **Purchases**
2. Tap **+ New Purchase**
3. Select vendor
4. Add products and quantities
5. Submit for approval

### 3.2 Receiving Stock

1. Find approved PO
2. Tap **Receive Stock**
3. Enter received quantities
4. Note any discrepancies
5. Confirm receipt

---

## 4. Stock Transfers

### 4.1 Requesting Transfer

1. Go to **Inventory** > **Transfers**
2. Tap **+ New Transfer**
3. Select source and destination shops
4. Add products
5. Submit request

### 4.2 Approving Transfer

Both shop managers must approve:
1. Source manager approves release
2. Destination manager confirms receipt

---

## 5. Stock Adjustments

### 5.1 Creating Adjustment

For breakage, expiry, or counting errors:
1. Navigate to **Inventory** > **Adjustments**
2. Select products
3. Enter adjustment quantity
4. Provide reason
5. Attach photo evidence if required
6. Submit for approval

---

## 6. Reports

Available inventory reports:
- Current stock levels
- Stock movement history
- Low stock report
- Expiry report
- Stock valuation
