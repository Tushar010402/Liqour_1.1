# Troubleshooting Guide

## Common Issues and Solutions

---

## 1. Login Issues

### Can't Receive OTP

**Symptoms**: OTP not arriving on phone

**Solutions**:
1. Check phone number is correct
2. Ensure network connectivity
3. Wait 2-3 minutes for delivery
4. Check SMS spam/blocked list
5. Try "Resend OTP"

### Account Locked

**Symptoms**: "Account is locked" message

**Solutions**:
1. Wait 15 minutes for auto-unlock
2. Contact your manager
3. Contact support if persistent

### Wrong Password

**Symptoms**: "Invalid credentials" error

**Solutions**:
1. Verify caps lock is off
2. Use "Forgot Password" option
3. Contact admin for reset

---

## 2. Sales Entry Issues

### Can't Find Product

**Symptoms**: Product not in search results

**Solutions**:
1. Check spelling
2. Try partial name search
3. Verify product is active
4. Contact admin to add product

### Price Mismatch

**Symptoms**: Displayed price differs from expected

**Solutions**:
1. Note the correct price
2. Contact manager to update catalog
3. Add note in submission

### Draft Won't Save

**Symptoms**: "Save failed" error

**Solutions**:
1. Check internet connection
2. Reduce image sizes
3. Try manual save
4. Restart app

### Can't Submit

**Symptoms**: Submit button disabled or error

**Solutions**:
1. Ensure at least one item added
2. Check all required fields
3. Verify date is valid
4. Review error message

---

## 3. OCR Issues

### Images Not Processing

**Symptoms**: OCR stuck at processing

**Solutions**:
1. Wait up to 15 minutes for large batches
2. Reduce batch size
3. Check image quality
4. Retry with fewer images

### Low Accuracy

**Symptoms**: Extracted data is incorrect

**Solutions**:
1. Use better lighting
2. Capture clear, focused images
3. Flatten creased receipts
4. Manual review and correction

### Upload Failed

**Symptoms**: "Upload failed" error

**Solutions**:
1. Reduce image file size
2. Check file format (JPG, PNG)
3. Check internet connection
4. Try one image at a time

---

## 4. Approval Issues

### Pending Too Long

**Symptoms**: Record stuck in pending

**Solutions**:
1. Contact manager directly
2. Check manager availability
3. Wait for escalation (24h)

### Unexpected Rejection

**Symptoms**: Record rejected without clear reason

**Solutions**:
1. Read rejection reason
2. Contact manager for clarification
3. Make required corrections
4. Resubmit with explanation

---

## 5. App Issues

### App Crashes

**Symptoms**: App closes unexpectedly

**Solutions**:
1. Update to latest version
2. Clear app cache
3. Restart device
4. Reinstall app

### Slow Performance

**Symptoms**: App responds slowly

**Solutions**:
1. Close other apps
2. Check internet speed
3. Clear app cache
4. Reduce data on screen

### Sync Issues

**Symptoms**: Data not updating

**Solutions**:
1. Pull to refresh
2. Check internet connection
3. Log out and log in
4. Wait for auto-sync

---

## 6. Notification Issues

### Not Receiving Notifications

**Symptoms**: Missing important alerts

**Solutions**:
1. Check notification permissions
2. Enable notifications in settings
3. Check Do Not Disturb mode
4. Verify phone settings

## 8. Emergency Procedures

### System Down

If LiquorPro is unavailable:
1. Record sales on paper forms
2. Photograph all receipts
3. Enter data when system restores
4. Mark as "delayed entry"

### Data Discrepancy

If you find data issues:
1. Don't modify records
2. Document the issue
3. Notify manager immediately
4. Wait for guidance

## 9. FAQ

**Q: How long does OCR take?**
A: Usually 1-2 minutes per image, up to 15 minutes for large batches.

**Q: Can I edit approved records?**
A: No, approved records are locked. Contact manager for adjustments.

**Q: What if I miss the 15-minute deadline?**
A: Collect as soon as possible. Incident is logged and manager notified.

**Q: How many devices can I use?**
A: Maximum 2 devices simultaneously. Third device logs out oldest.

**Q: Can I work offline?**
A: Limited functionality. Data syncs when connection restores.
